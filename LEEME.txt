BUSCADOR VEHICULAR - VERSION ROJO ELECTRICO

Archivos:
- index.html: pagina web con el diseño rojo eléctrico.
- datos.json: registros consultados por el buscador.
- logo-utp.png: debes agregar el archivo de imagen del logo UTP en esta misma carpeta.

Para publicar en GitHub Pages:
1. Sube index.html y datos.json a la raíz del repositorio.
2. Si quieres mostrar el logo, sube también logo-utp.png a la misma raíz.
3. En Settings > Pages, configura Deploy from a branch, rama main y carpeta /(root).

El HTML referencia el logo mediante ./logo-utp.png. Si el archivo no existe, el logo no aparecerá; la página y la búsqueda seguirán funcionando.
